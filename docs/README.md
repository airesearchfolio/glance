# GLANCE project page
Static site (no build step). Upload the contents of this folder to the root of the GitHub Pages branch (or to /glance/ in airesearchfolio.github.io).
- index.html: the page
- images/: figures and example radiographs
- katex/: pre-rendered equation styling (self-contained, no CDN needed for math)
Only Google Fonts (Inter, JetBrains Mono) loads from a CDN; the page falls back to system fonts if blocked.
